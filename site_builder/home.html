The problem

Default MCP deployments give every tool the keys to everything

01

Identity Flattening

Every tool runs under one shared, elevated credential. A read-only lookup and a destructive write carry the same authority.

AC-3 · AC-6
02

Indirect Prompt Injection

A poisoned document, ticket or email hijacks the agent and triggers tool calls nobody approved.

SI-10 · SI-16
03

Audit Blind Spots

Logs show an API call but not which person, which agent or which tool. You can't prove what happened.

AU-2 · AU-12
